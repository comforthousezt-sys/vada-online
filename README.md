# VADA Online · 0.2.0 alpha

Українська браузерна економічна гра про NUMBRA, переговори й парламент.

Ця збірка містить завершувану партію на 3–5 учасників, ботів, процедурну 3D-мапу Babylon.js, приватні мережеві кімнати, чат і двосторонній обмін. HOSTiQ віддає статичний сайт, Render запускає сервер Node.js, PostgreSQL зберігає приватний стан кімнат.

Почніть із [INSTALL_UA.md](INSTALL_UA.md). Правила: [RULES_UA.md](RULES_UA.md). Статус можливостей: [docs/RELEASE_UA.md](docs/RELEASE_UA.md).

## Локальний запуск

Потрібен Node.js 24.19.0 або сумісний Node >=22.12.0.

```bash
npm ci
npm run dev
```

Відкрийте http://127.0.0.1:5173. Гра з ботами працює відразу. Для кімнат у другому терміналі:

```bash
ALLOWED_ORIGINS=http://127.0.0.1:5173 npm run dev:server
```

Для Windows PowerShell перед запуском установіть `$env:ALLOWED_ORIGINS="http://127.0.0.1:5173"`. У `web/public/config.js` задайте `apiBase: 'http://127.0.0.1:10000'`. Поверніть його до адреси Render або порожнього рядка перед виробничою збіркою.

Без DATABASE_URL локальний сервер використовує `data/`; ці приватні файли виключені з Git. Ніколи не завантажуйте їх у публічну папку сайту.

## Збірка й перевірка

```bash
npm test
npm run build
npx playwright install chromium
npm run test:browser
```

Браузерна перевірка запускає сайт із `dist/` у підкаталозі `/vada/`, HTTP/WS-сервер і дві незалежні сесії. Вона перевіряє купівлю, збереження, вибір активу для карти, обмін, чат, повернення до кімнати та повторне підтвердження дії після втрати ACK. За потреби можна задати `BROWSER_EXECUTABLE` шляхом до сумісного Chromium. Звіти й знімки записуються в `docs/`.

`npm run build` створює `dist/` для HOSTiQ і `server-dist/` для сервера. `npm start` запускає лише сервер кімнат. `render.yaml` містить конфігурацію Render Blueprint із планом Free. Віддалені сервіси не створюються командами збірки чи тестами.

## Структура

| Папка / файл | Призначення |
|---|---|
| `shared/` | Єдині правила, контент, типи та боти |
| `web/src/` | React-інтерфейс, SVG NUMBRA, процедурна Babylon-сцена |
| `web/public/config.js` | Публічна адреса API, яку можна змінити без збірки |
| `server/` | HTTP/WS, приватні проєкції, контроль версій і збереження |
| `server/schema.sql` | Приватна таблиця кімнат PostgreSQL / Supabase |
| `tests/` | Правила, перезапуск, мережеві запити та браузерні сценарії |
| `render.yaml` | Розгортання одного сервера кімнат |

Це перевірена локально альфа. Реальний домен, SSL, Render і підключення Supabase потрібно перевірити після встановлення за інструкцією. Публічні облікові записи, оплати, колекція, QR, гібриди та сюжетні кампанії описані як наступні етапи.
